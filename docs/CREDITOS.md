# Fuentes, licencias y autoría

Los modelos del club son geometría original generada para esta entrega mediante fuentes editables y asistencia de Codex. Se conservan código, JSON de geometría y mallas Unity. No se usaron modelos externos descargados.

| Recurso | Origen y tratamiento |
|---|---|
| Plantilla web | [Needle Vite Template](https://github.com/needle-engine/vite-template), adaptada a este juego. Se sustituyeron escena demo, interfaz y lógica. |
| Runtime y exportador | Needle Engine 5.1.16; sujetos a [su EULA](https://needle.tools/eula). Uso académico, licencia Basic detectada. No se alteró el SDK para saltar licencias. |
| Three y utilidades | Distribución de Three de Needle, instalada por npm. Se utilizan RoundedBoxGeometry y mergeGeometries. Conservar avisos de sus dependencias. |
| Fuentes de interfaz | DM Sans y Space Grotesk, consultadas mediante Google Fonts. El CSS incluye alternativas de sistema si no cargan. |
| Imagen inflable | Referencia proporcionada por el equipo. Autor/licencia sin confirmar. Se estudió material y costura; no se reprodujeron emblema ni silueta del personaje. Excluida del repositorio. |
| Diorama de Needle | Referencia proporcionada por el equipo. Autor/licencia de la captura sin confirmar. Se estudió composición y facetas. Excluida del repositorio. |
| Paleta | Propuesta del equipo en el encargo; inspiración de ambiente de Moonlighter (Digital Sun) y Core Keeper (Pugstorm), sin extraer sus assets. |
| Sonido | Tonos sintetizados en Web Audio, sin archivos musicales externos. |
| Texturas | Generadas por `tools/bake.py` y horneado real de Unity. Se conservan fuentes y mapas. |
